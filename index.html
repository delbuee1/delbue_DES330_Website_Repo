    Welcome

    Hello and welcome to BioTracker, a 100% fan run and operated achievement tracker for the Resident Evil series! This is a fan project that is not affiliated with Capcom whatsoever. Resident Evil and the screenshots used are property of Capcom Co., Ltd.

    I created this to give players an easy and consolidated resource to help track achievements, and because I wanted to stick to my nerdy interests for this assignment. I've noticed that a lot of achievement tracking websites would limit the amount of times you can mark off an achievement as completed, or would force you to sign in. That really bugged me, so I wanted to create a website to track achievements without these limitations.
